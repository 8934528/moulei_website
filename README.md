# Moulei Portfolio System Website

A professional **portfolio system-style website** for **Moulei**, an HR professional with 4 years of work experience.  
**Note:** *Moulei is a demo/mock name created for this project.*

This website uses a **tab-based layout (not a navigation bar)** and is designed to look like a modern system dashboard

---

## Features

- Full screen system layout (100% width and height)
- Tabs (NOT navbar)
- 3D hover effects on cards
- 3 hover effects (buttons, cards, pills, images)
- Smooth animations (fade-in, slide, pulse, progress bars)
- Dark Green + White + Orage theme
- Uses **Bootstrap 5** for layout structure
- Uses **FontAwesome** icons
- Mobile responsive
  - Tabs move to the bottom like a mobile app
- Includes 3–4 online images
- Includes favicon
- Simple English content and simple code

## Theme Colors

The website follows a professional theme using:

- **Dark Green** (main background)
- **White** (text and UI)
- **Orange** (highlight and active states)

---

## Tabs Included

The system contains 5 main tabs:

1. **Home** – Welcome page and images
2. **About** – Summary and timeline
3. **Skills** – HR skill bars and soft skills
4. **Work** – Experience cards
5. **Contact** – Contact form and social icons

---

## Mobile Responsiveness

On smaller screens:

- The sidebar becomes top content
- Tabs move to the bottom
- Icons remain visible
- Layout becomes stacked and readable
